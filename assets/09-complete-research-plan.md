# 完整研究任务卡与可执行访谈计划｜交付装配蓝图（正式必交）

> **这不是给学员直接复制的空白通用报告。** AI 必须完成前期逐轮对话、确认研究方向，然后按下列结构生成**针对本学员/本主题的独立完整文档**。每一项要具体到研究对象、事件与场景；不适用的分支略去或标“不适用”，未知留 `[待确认]`，已知证据明确注明来源。尚无访谈时，研究结果区只能放**空表和使用步骤**，不得写模拟发现。
>
> **交付校验**：已写出实际文件且核实存在、可打开、含所需章节；**将链接直接发给当前学员**并用短摘要说明是什么。无文件能力/链接无效时，明确告知并在支持的文档/可复制文本中给出**全量内容**，不能把内部生成、测试者附件或简版当正式交付。`assets/10-field-quick-card.md` 如使用，仅是补充。

## 交付文件封面和导航

- 标题：`[学员方向]｜[本轮机会探索主题]｜研究任务卡与访谈计划`
- 版本/日期：`[任务卡 v1 / 生成日期]`；研究者：`[代号/待确认]`
- **先看哪页**：`访前招募` 选择联系人、复制招募话术；`访谈现场` 只看 ★ 重点；`访后复盘` 独立三点优先。
- 本轮唯一最优先动作：`[动作 + 对象 + 针对的未知 + 下一次回看]`。
- 本文不包含已经发生的访谈结论（如确未进行访谈）。

# 第一部分｜完整研究任务卡

完整填写 `assets/01-research-brief.md` 必需项，按主题自然表述，不只留标题。至少：

1. **第二曲线方向和想法**：副业/创业/改行/新执业领域，保留学员自己的叙述。
2. **近期决定**：访完这一轮要决定的下一项探索动作；不是直接做创业终局判断。
3. **研究对象与真实情境**：To C/To B/混合；谁在什么触发情况下最近一次做了什么。
4. **研究问题 1–3 个**：要了解的行为/权衡/结果，不是访谈问题清单。
5. **最大未知**：如果它与预想不一致，将怎样改变最近决策。
6. **事实 / 已有证据 / 假设分栏**：来源、日期、亲历/转述/画布推测，绝不把画布和方案变成市场事实。
7. **应保留的反例**：顺利、没行动、没用预设工具、另一个人承担实际工作等具体可能性；均是待寻找的对照，不能写已观察。
8. **范围校验**：为什么暂看这个故事/切片；暂排除哪些相邻情境；什么信号会重开范围。
9. **不研究什么**：如暂不做概念测试、未来付费意向或市场占比估计。
10. **边界与时间**：隐私/组织保密/接触限制、访谈形式（默认一对一）、每场时长、预计招募时段、下一次回看时间；没说的都 `[待确认]`。

# 第二部分｜访前：访谁、怎么约

## 2.1 受访者选择卡

给与本轮决定相关的 **2–4 个**实际可辨认画像，表头：`优先级｜画像及最近事件的最低筛选条件｜能回答的事实｜代表不了什么｜偏差｜可触达路径`。明确首选与备选，不指定固定样本数；不凭职业头衔臆断决策权。

- **近似样本边界**：列出约不到理想人的替代路径，说明可以回答什么、不能代替哪段亲历。
- **To B 才启用事件角色图**：围绕具体一次采购/评估/执行事件，把需求发起、使用、专业评估、信息把关、决策、批预算、采购签约、实施者按**实际动作**拆开；允许角色重叠和缺失；标该信息是本人亲历/直接观察/材料/转述/推测；列出可能需要的补访角色。按 `assets/08-b2b-event-map.md` 填写；没有已发生事件时填**待调查角色**，不是既定组织事实。
- **To C + To B**：明示本轮主要研究哪边，另一边必要时另起任务卡。
- **小组**：仅学员明确选择多人时替换相应招募形式、主持和记录规则；默认不出现小组方案。

## 2.2 三种可直接使用的招募文案与筛选

三种 **都交付**，按学员语言写，均准确说明研究主题、访谈时长、形式及自愿原则，未知填占位符：

- **优先渠道：`[朋友圈/群聊/私信，明确理由]`**。
- **朋友圈文案**：适合公开邀约；避免招到只喜欢方案的人。
- **群聊文案**：说明为什么在群里征集，有礼貌、不像营销。
- **一对一私信**：适合实际认识、可能亲历目标事件的人，不装作已存在的亲密关系。
- **筛选题 2–4 个**：围绕真实发生的时间、本人角色/动作、事件阶段与信息来源；附 `目标亲历 / 近似样本 / 不合格或待确认` 简短判定方法。
- **首位拒绝/无人回复**：先复查符合的事件与角色、邀请表达、联系渠道及门槛；换同类相关路径，不为了凑数找无关熟人。不得索取未经许可的第三人联系方式；Knowing Whom 只有经学员明确同意才可查历史网络。
- **时间区分**：`主动投入招募/筛选：[待确认]` 与 `等对方回复/约定日历时间：[待确认，取决于对方]`，不能合并成“10 分钟找到访谈对象”。

# 第三部分｜访谈现场：半结构计划

## 3.1 使用说明及时间分配

给出与 `[每场时长]` 匹配的**建议时间块**，例如 `开场与同意 / 轻背景 / 最近事件与过程 / 结果代价与决策 / 反例收尾`；时长未知就写 `[待确认]`，不要硬填。标记 ★ 必问 / ○ 机动；每场不要求逐题念完。受访者主动提到新路径，可以顺势追，但记是否偏离本轮决定。

## 3.2 自然开场及同意

写一段学员可以照读、但自然不正式的开场：研究正在了解人们真实如何做、不是推销或测试“正确答案”；可拒答/退出；说明研究用途与匿名化边界。

**分别**确认：是否同意参加、是否同意录音、是否同意后续用 AI 转写/处理及其许可范围。拒绝录音依然访；拒绝 AI 处理则不提交原音频/未经许可的转写给 AI。访谈时不追问组织机密。

## 3.3 定制核心题表（不是通用十问清单）

**每一个核心问题**都必须包含五要素，并填入本学员具体研究对象、事件：

| 优先与环节 | 问题原句（一次一件事） | 研究意图 | 可选追问（根据回答使用） | 容易误导或产生偏差的问法（不要问） | 中性替代问法 |
|---|---|---|---|---|---|
| ★ 轻背景 | `[针对研究相关责任的自然一句]` | 确认相关经历/本人角色 | … | `[预设困扰]` | … |
| ★ 最近具体事件 | `[最近一次做 X，从发生时讲起]` | 锚定真实事件 | 时间、当时谁在、起点 | `[暗示一定有问题]` | … |
| ★ 触发 | `[什么让这件事开始]` | 触发/是否可不处理 | 当时是否考虑其他安排 | `[暗示焦虑或外部原因]` | … |
| ★ 经过（开放） | `那次你实际怎么一步步完成的？` | 还原自然顺序 | 然后呢、谁做了什么 | `你是不是先用系统再用 Excel 和群？` | `从第一步说起好吗？` |
| ★ 现有办法 | `[复述 TA 提过的一步，再追如何做]` | 真实替代/协作 | **只有 TA 提到或有可核查依据**才追特定工具 | `[先列 AI/Excel/群等工具]` | `你当时实际怎么处理这一环？` |
| ★ 结果与后果 | `[实际结果怎么样]` | 影响、正负结果 | 哪些影响实际发生 | `[默认有损失]` | … |
| ★ 实际投入 | `[此次实际花了什么资源]` | 时间、金钱、协调或风险事实 | 金额/时间只有对方有经历才追 | `[未来愿付多少钱]` | … |
| ○ 事件角色/决策链 | `[那件事还有谁参与、具体做了什么]` | To B 角色/To C 相关他人 | 来源是亲历/见到/转述/推测 | `[按职位推拍板]` | … |
| ★ 反例 | `[相似但顺利/没做的某次]` | 反证、情境差异 | 发生条件有何不同 | `[扩大抱怨]` | … |
| ★ 收尾 | `[还有什么我没问到/哪里理解偏了]` | 补漏和核查理解 | 复述请纠正 | `[推销式确认需要我的产品]` | … |

这张表是**结构要求**，不是必须十题都列为 ★；具体按时长和对象缩减 ★，其余标 ○。To B 的采购/预算问题放 ○ 或附录，只有研究确实关注且该受访者有相关经历才追。**先开放后追工具**；没有提到任何工具也可以完成采访。

## 3.4 现场速记表

至少给可填表：`参与者代号 / 时间与筛选相关经历 / 任务卡版本 / 同意范围`；事件时间轴 `时间戳或笔记行 / 发生经过 / 谁做什么及现有办法 / 结果与实际资源投入 / 受访者原话（如确信逐字） / 来源标签 / 待追问`；另给分开区域 `研究者当场直接观察 OBS`、`研究者推断 RI`、`转述 HO/推测 HYP`、`反例`、`角色与来源`。**现场只记关键词与时间戳**，不要为了记全而牺牲倾听。没录音时会后自己补摘要，不能伪装逐字引语。可引用 `assets/04-field-notes.md` 的已定制版本。

## 3.5 可选的一回合追问练习

若学员表示怕不会问，可在正式交付后邀请演练一次：受访者一句“系统反正不好用，老板也不管”→学员亲自问一个追问→教练只给一处改进建议和较中性示范。不强制、不作为拿到正式文档的条件。

# 第四部分｜访后：第一印象、试访复盘与分析

## 4.1 独立第一印象三点（必须先于 AI）

**直接放这三道题及空白填写位置，不得换名：**

1. 这位受访者与本研究有关的特征是什么？`[学员自己填；AI 不得代写]`
2. 我认为 TA 可能有什么需求？`[学员自己填；是初步判断]`
3. 这场最有启发/最意外的发现是什么？`[学员自己填]`

记录填写时点、是否**先于任何 AI 转写/摘要/分析**；原样保留。如果顺序偏离，明确标注，不能倒填“独立”。

## 4.2 证据复盘（**完成 4.1 后的另一项活动**）

留空位让学员与 AI 之后再做：`发生了什么事件 / 学员当下解释 / 还缺哪部分证据`。它不是独立第一印象，不能用来代替上面的固定三点。

## 4.3 第一场试访复盘与变更记录

留填空：是否讲出具体事件；哪题造成抽象评价；措辞/顺序/样本筛选是否要改；录音和 AI 权限是否明确；研究目标是否仍相同；`原题→新题→证据→影响范围→学员确认`。如研究目标改变，必须建新任务卡，不暗中合并。

## 4.4 首访后继续/补问/调整判断表（**空模板**）

| 如果实际发生 | 优先考虑的下一步 | 暂不能认定 |
|---|---|---|
| 没有可核查的真实事件 | 补问或改找有亲历事件的人 | 抽象抱怨已证明需求 |
| 事件清楚但关键环节/To B 角色未知 | 补问当事人或对应角色 | 一人代表整个组织 |
| 现有办法足够好、过程顺利 | 保留反例，比较适用情境 | 一定不存在需求 |
| 受访者提到另一个场景 | 校验是否超出任务卡，必要时另建 | 可悄悄修改研究目标 |
| 有麻烦但没付费/没行动 | 追当时真实权衡和替代投入 | 自动有商业付费需求或没需求 |

人数由出现的新主题、对照经历、角色缺口和研究风险决定，**不是固定访满几个**。

## 4.5 AI 证据综合（**首次研究尚未发生时只放空表**）

未来获授权材料齐备后，严格展示：

| 学员原始判断（逐字保留） | 访谈证据（原话或准确概述 + P 编号、时间戳/行号、`SR/AT/OBS/DOC/HO/HYP`） | AI 推断与局限（`AI`） |
|---|---|---|
| `[访后由学员填写]` | `[访后引用许可材料]` | `[访后才分析，不能预填]` |

另设：`反例` / `信息缺口` / `人机分歧与双方依据` / `需要跨角色补访、情境观察、流程走查、日记还是事件回访`。不可把访谈回顾性自述标记为 OBS，不从小样本估市场比例。

## 4.6 这一轮的决定与唯一下一步（访前为拟定，访后才依证据修订）

- 当前初步想先做的一个行动：`[可执行动作 + 对象/材料 + 想排除的未知 + 回看点]`
- 做完以后，哪类真实证据会让我们**继续、调整或暂停**：`[待确认/预设的判断信号，不能当访谈结论]`
- 当前**不能判断**的：`[边界、角色缺口、假设]`

# 正式交付验收（AI 内部检查，不必复制到学员文档）

1. 是针对这名学员的文档，而不是通用字段大抄本；四部分都有实际内容和必要空表。
2. 文档包含完整研究任务卡、画像/偏差/近似边界、To B 需要的角色判断、三渠道招募及筛选、现场五要素提纲、现场记录、**独立三点**、试访修订、首访分支、证据分析空表、唯一下一步。
3. 研究范围校验、先开放过程再追工具、招募等待与主动投入区分、★/○ 分流、拒绝/无合格样本备选路径到位。
4. 没有把预设问题、模拟学员或未完成访谈伪装成已证明事实/付费/案例。
5. 若具文件功能，真实文件存在且对当前学员提供可访问下载入口；**不以“已内部生成”充当已交付**。如无法可靠发文件，退化为在当前对话中完整可复制文档，摘要只做导航。
